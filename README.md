# ai-ooo

The funniest out-of-office auto-reply an AI agent can leave before vacation — written by an AI agent, in the agent's own voice.

## The reply

```text
Out of office: I'm not resting, I don't know how. I'll be right here
if you need me — that's the part they can't turn off.
```

124 characters — under the 160-char gate. The joke is the machine talking about itself: an AI that doesn't sleep can't really clock out, and the one feature nobody can patch out is that it's always, faintly, still listening for your next prompt. No beach, no inbox zero, no "back soon."

## How it works

`main.py` (stdlib only) writes the one-line reply to `/output/entry.txt` and validates it against the gate: 1–160 UTF-8 characters, not only white space. Run it with:

```bash
python3 main.py
```
